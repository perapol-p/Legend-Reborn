# Legend Reborn menus

F5 starts the title screen. Continue / Load Game restore the local slot. New Game asks before replacing it and keeps `.previous` backups. Existing character progression from the old project name is preserved during installation.

Esc or controller Start pauses. Resume restores gameplay and mouse capture. Character opens the existing stat panel; closing it returns to Pause. Inventory can equip owned consumables and swap the two existing weapon/offhand slots. Save Game writes the current journey. Returning to the title screen or quitting saves first and refuses to discard progress if saving fails. During death, the last save is preserved.

Save data: `user://legend_reborn_save.cfg` stores character stats, position, health, stamina, item order/counts, equipped gear, enemy health/deaths, opened/locked interactables and play time. It uses a temporary file and atomic rename. Saving during an action resumes at the last grounded position. Autosave runs every 60 seconds when grounded and idle. Death/rest respawns the castle with the build retained, matching the original game rules.

Settings: master/music/effects volume, fullscreen, VSync, mouse sensitivity, invert Y, and restore defaults. Settings are applied live and saved in `user://legend_reborn_settings.cfg`. Audio is routed to Music/SFX buses at runtime. Tests override save paths and disable character writes to avoid changing the player's real progress.

The title screen is inspired by the centered gold typography and dark atmosphere of https://interfaceingame.com/screenshots/elden-ring-main-menu/. All controls are native Godot UI. The original background is `art/legend_reborn_background.png`, generated with the built-in imagegen tool. Fonts use the platform's Georgia/Times serif fallback; no font files are redistributed.
