# Legend Rebron - Godot 4 Project

Starter 3D Godot project based on the supplied menu wireframes.

Implemented:
- Main Menu: Play, Setting, Credit, Controls, Exit
- Game title: Legend Rebron
- Settings without VSync
- Master/Music/Effects volume UI
- Mouse sensitivity, Fullscreen, Invert Camera Y
- Persistent settings via ConfigFile
- Character Select: Daddy available, Mommy locked until 1 completed game, Son placeholder locked
- Character Detail screen
- 3D gameplay placeholder scene
- Exit confirmation

Open `project.godot` using Godot 4.x and press F6/F5.
