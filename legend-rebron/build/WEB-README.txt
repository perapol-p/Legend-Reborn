Legend Reborn - Web release
Upload build/Legend-Reborn-Web.zip to itch.io as an HTML game.
Enable "This file will be played in the browser"; use a 1280 x 720 embed.
Low graphics is the default on Web. Select Medium/High in Settings on stronger computers.
Click the game to capture the mouse. Escape opens Pause.
Detailed build notes: docs/web_build.md.
