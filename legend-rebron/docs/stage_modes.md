# Stage selection and modes
PLAY opens stage_select.tscn with three English options: Grassland (Normal Mode), Desert (Normal Mode), Practice (Sandbox). After choosing a stage, the existing character selection/detail flow starts that stage. Character selection Back returns to stage selection. Retry keeps the selected stage; Main Menu returns to the lobby. F1 works on the stage screen.
Grassland and Desert are simple initial map variants sharing the existing arena's collision layout, ramps and pyramids. Grassland uses a green floor and trees; Desert uses a sand floor and stone ruins. Their native map scenes inherit fps_arena.tscn and use stage_arena.gd for materials/decorations. Both run normal enemy progression, the 15-minute boss and overtime pressure.
Practice uses the original grid arena unchanged. Automatic spawning/difficulty/boss arrival is disabled. F1 provides /weapon, /weaponlevel, /levelup, /target and /spawn melee|archer|flyer|boss [1-10]. Manual enemies spawn while the console pauses gameplay, and become active after closing it. Defeating a manually spawned practice boss does not count as a completed normal run. /spawn is refused in Normal Mode. Music/SFX and combat still work in all modes.
GameData.selected_stage records the selection for the current app session. The game selects its arena during _enter_tree before gameplay binding. Selection defaults to Grassland when starting a new app session.
