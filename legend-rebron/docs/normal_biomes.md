# Normal biome maps

Grassland and Desert use deterministic low-poly terrain generated by scripts/stage_arena.gd. Practice keeps the existing grid arena.

- Grassland: broad rolling hills, dirt paths, broadleaf/pine trees, a stone arch and standing stones.
- Desert: dunes, cacti, sandstone gate/obelisks and a decorative oasis with palms.
- Terrain is a 4 m triangle grid with matching collision and height interpolation. The central spawn clearing remains flat. Props use shared MultiMesh batches; tree/cactus trunks and rocks have collision.
- Perimeter cliffs replace the visible box walls; inherited wall collision remains behind the cliffs. Normal enemy spawn positions stay inside 73 m on each axis.
- Hills have gentle slopes so player and ground enemies can reach their tops without special ramp waypoints. Existing enemy availability, difficulty and the 15 minute boss timing remain intact.
- Terrain is identical each time a stage loads, allowing the single-slot run save to retain actor positions. Loading raises actors above the new ground if an old saved position lies beneath a hill.
- Ground uses broad color changes, no animated textures or dense grass. Lighting has been checked through rendered FPS previews.

Validation: backups/verify_biomes.gd checks both stages, ground ray collision, walkable normals, all three enemy spawns, player walking up hills, old-position clearance and unchanged Practice terrain. Graphics runs retain the previously observed Godot texture-leak warning on shutdown.
