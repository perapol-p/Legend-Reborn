# Practice tools panel
In Practice (Sandbox), U opens/closes the English Practice Tools UI; Escape also closes it. The modal pauses gameplay, releases the cursor and blocks pause/reward keyboard handling underneath. U is reserved from rebinding. Normal Mode does not create the panel.
All existing console actions are available as 24 command buttons: four enemy types with spawn count 1-10; training target; five weapon choices; character/weapon level up; combo hit/kill/reset; four character unlock choices; debug on/off; spawn info; help; clear output. Two extra UI controls open the text console or close/resume. Buttons reuse command_console.submit so validation and behavior match F1 commands. The panel shows current levels, enemy count and scrollable command output.
Character Level +1 closes the panel before opening the existing item-choice overlay. Pending item choices must be completed before reopening the panel. F1 switches from the panel to the old text console; typing in the text console does not trigger U. Game Over/Victory closes and disables the tools. Character unlocks are still saved through the existing progress system.
Validation: backups/verify_practice_tools.gd checks U/Esc/F1, spawning count, weapon upgrades, combo/debug utilities, unlocks with a separate test save, item selection, cursor/pause restoration and Practice-only availability.
